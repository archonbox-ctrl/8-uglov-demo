# 8 Углов

Демонстрационная версия сайта «8 Углов»: интро с 3D-анимацией, страницы услуг и кейсов, каталог инструментов с поиском и фильтром, контакты. Для посетителя это **статический сайт**: серверное API, база данных и секретные ключи для его работы не требуются. При отключённом WebGL или настройке уменьшения движения интро использует облегчённое представление.

## Локальный запуск

Понадобятся Node.js 22 и pnpm 10.18.0. Из корня проекта:

```bash
corepack enable
corepack prepare pnpm@10.18.0 --activate
pnpm install --frozen-lockfile
pnpm check
pnpm dev:static
```

Откройте адрес, выведенный Vite; по умолчанию это `http://localhost:3000/`. Контактные кнопки открывают соответствующие мессенджеры без автоматической отправки сообщения.

## Статическая сборка

```bash
pnpm build:static
```

Готовые файлы находятся в `dist/public/`. Сборка создаёт HTML для существующих страниц, индекс маршрутов и текстовые материалы для AI-агентов; `dist/public/404.html` используется для неизвестных адресов на поддерживающем его хостинге. Файлы каталога и тексты страниц редактируются в исходном коде — панели управления и базы данных нет.

## GitHub Pages

Для сайта вида `https://<имя-пользователя>.github.io/<имя-репозитория>/` задайте **точное** имя репозитория в базовом пути перед сборкой. Пример для `8-uglov-demo` в macOS/Linux/Git Bash:

```bash
VITE_BASE_PATH=/8-uglov-demo/ pnpm build:static
npx --yes gh-pages@6.3.0 -d dist/public -b gh-pages --dotfiles
```

В PowerShell:

```powershell
$env:VITE_BASE_PATH = '/8-uglov-demo/'
pnpm build:static
npx --yes gh-pages@6.3.0 -d dist/public -b gh-pages --dotfiles
```

Команда `gh-pages` требует настроенного доступа на запись в удалённый репозиторий GitHub. В настройках репозитория **Settings → Pages** выберите **Deploy from a branch**, ветку `gh-pages` и папку `/(root)`. GitHub Pages может потребовать публичный репозиторий или подходящий платный план. Публикация происходит не мгновенно: проверяйте её результат и адрес на странице Pages. При использовании корня домена вместо подпапки задайте `VITE_BASE_PATH=/`.

Сборка настроена как **демо для согласования** и содержит `noindex, nofollow`; эти директивы не ограничивают доступ к сайту. До полноценного запуска необходимо отдельно согласовать содержимое, юридические документы и права, а также настройки индексации, канонических адресов и аналитики. GitHub Pages не предоставляет серверные API или базу данных.

## Безопасность и материалы

Не добавляйте в репозиторий файлы `.env`, токены, ключи, журналы, клиентские базы, исходные архивы и другие конфиденциальные материалы. До размещения новых изображений, сертификатов, персональных данных и кейсов необходимо получить разрешение правообладателей. Сам факт публикации демонстрации не даёт разрешения на повторное использование материалов третьими лицами.
